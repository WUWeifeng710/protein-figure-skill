# Guides

Full skill usage guides (cases + sample figures + install instructions), in two languages.

| File | Language | Size |
|---|---|---|
| `protein_figure_skill_guide_zh.pdf` | 中文 | ~10 MB (15 embedded 1AY7 sample figures) |
| `protein_figure_skill_guide_en.pdf` | English | ~10 MB (15 embedded 1AY7 sample figures) |

## Contents (both)

1. What the skill does
2. Environment & installation (conda-forge PyMOL 2.5.0 + PyMOL-PUB)
3. Two rendering paradigms + 2.5.0 strict-API cheatsheet (top 6 gotchas)
4. Style recipe overview (10 direct-cmd + 3 standard-class templates)
5. Four worked cases with runnable code (Goodsell / active-site / RMSD overlay / journal layout)
6. Publication quality constraints (journal DPI tables, OPIG params)
7. Deliverable & labeling conventions
8. 14-image sample gallery (all rendered from 1AY7, 1600×1600, 300 DPI)
9. **Borrows From** — the full list of upstream projects this skill builds on
   (PyMOL-PUB, PyMolClaw, google-deepmind/science-skills, schrodinger/pymol-open-source,
   cgohlke wheels, OPIG, user .pml recipes)

> **Why PDF, not Markdown?** The guides embed 15 sample figures (PNG, 1600×1600, 300 DPI).
> The figures do not live in this repo — the `.md` versions therefore render broken
> images on GitHub. The PDFs are self-contained: every figure is embedded, so they
> display correctly anywhere (browser, print, Airplane mode).
